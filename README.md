# ORIGIN Atelier · Конструктор колец

Интерактивная ювелирная витрина. Прокрутка ведёт зрителя через этапы создания кольца. В конструкторе можно изменить отделку и камень. Выбор сохраняется в браузере при следующем открытии.

[Открыть работающий конструктор](https://anatoliyroslyakov-ring-constructor-c87d.twc1.net/).

## Как устроен проект

- JavaScript и Three.js отвечают за трёхмерную сцену и просмотр изделия.
- GSAP ScrollTrigger связывает главы с прокруткой. Интерфейс учитывает системную настройку уменьшенного движения.
- Ширина шинки, размер камня, огранка и тип оправы меняют геометрию модели. По той же конфигурации формируется спецификация с размерами, металлом и гравировкой.
- Конфигурация кольца сохраняется в localStorage. Исходная точка входа — [src/main.js](src/main.js).

## Запуск

Для просмотра собранной версии нужен Python 3. Из корня репозитория выполните `python3 server.py` и откройте [localhost:8765](http://localhost:8765).

Для изменений JavaScript установите Node.js и выполните команды из корня проекта.

```sh
npm install
npm run build
npm start
```

Сборка выполняется через esbuild. Локальный сервер обслуживает собранные файлы и ресурсы витрины.
